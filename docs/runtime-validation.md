# Runtime Validation

BGVD-State v1.1.1 separates software validation from the security-replay workload used in the accompanying study.

## Complete Engineering Case

`examples/discovery_runtime_case/events.json` is a de-identified, real-workflow-derived event sequence. It contains 23 events, six candidates, five failed paths, six material-evidence records, and two verifier results for the final candidate. The earlier technical verifier is positive; the current scope verifier is negative, so the gate blocks finalization while preserving both events.

The scope decision is external input. BGVD-State does not infer a threat model or disclosure policy.

## Determinism and Checkpoint Resume

Run:

```bash
python tools/validate_runtime_engineering.py \
  --out-dir validation/runtime --repeats 100
```

The released report records:

- 100 identical state hashes;
- 100 identical handoff hashes;
- 100 identical gate-decision hashes;
- equality between uninterrupted replay and save/load checkpoint resume;
- rejection of duplicate event identifiers;
- rejection of malformed JSONL with a line-numbered error; and
- successful loading of a state file generated by v1.0.0.

Checkpoint equivalence is not the same as a distributed transaction. State and CLI JSON writes use atomic same-directory replacement, but the runtime does not coordinate multi-file transactions or concurrent writers.

## Performance

Run:

```bash
python tools/benchmark_runtime.py \
  --sizes 100 1000 10000 100000 \
  --repeats 5 --candidates 6 \
  --out-dir validation/runtime
```

The benchmark measures event generation, replay, state serialization, handoff construction, and Python allocation peak on one Windows workstation. It uses six concurrent candidates at every event volume. The results characterize event-volume scaling for this profile; they do not establish scaling to an unbounded number of candidates, concurrent producers, or distributed storage.

Machine-readable outputs are `validation/runtime/runtime_engineering_validation.json` and `validation/runtime/runtime_benchmark.json`.
